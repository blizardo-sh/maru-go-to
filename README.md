# Японский: тренажёр к очным занятиям

Онлайн-приложение для нескольких учеников по Marugoto Starter A1: выбор материала всех 18 уроков, словарные карточки в двух направлениях, аудирование, конструктор предложений, личные списки и свободный разбор. У каждого ученика отдельные настройки и прогресс. Во всех 18 уроках доступны необязательные официальные видеодиалоги по коммуникативным целям: 44 Practice и 36 разговорных Challenge, всего 80 клипов. Для каждого сохранены оригинал и японский текст из официальной разметки; Challenge могут содержать инструкции и образцы, а не только произнесённые реплики. [Источники и охват библиотеки](docs/research/marugoto-video-library.md). Вход по email и паролю; регистрация — по персональному приглашению или регистрационной ссылке администратора.

Редакция 22 октября добавляет практику счётных суффиксов с картинками и аудио, числовые ступени до миллионов, переворот и колоду всех словарных/аудиокарточек. Это новая локальная реализация; производственный выпуск этой редакции ещё не выполнялся. Проверки и границы — в [VERIFICATION.md](docs/VERIFICATION.md).

Производственный HTTPS и все три контейнера проверены 21 октября 2026 года. В CI проходят 77 тестов на PostgreSQL 18.6, браузерный вход и Linux-образы с реальным защищённым профилем. Внешняя зашифрованная копия восстановлена в отдельную БД; публичные проверки доступа и безопасности описаны в [DEPLOYMENT.md](docs/DEPLOYMENT.md).

В выбранном интерфейсе «Альбом» часть урока начинается с обзора до пяти слов: иллюстрация слева, кана/перевод/проверенное кандзи справа, компактный JP/RU-пример с аудио. Практика слов использует четыре ответа и серверную оценку; повторения и конструкции сохраняют свои действия. Согласованный объём и реальная приёмка описаны в [UX-плане](docs/compact-study-ux.md) и [browser harness](verification/album-learning/README.md). Наличие кода в ветке не означает его публикацию на производственном сайте.

## Локальный запуск

Нужны Bun 1.4.3 и отдельная PostgreSQL. Версии зависимостей закреплены в `bun.lock`; `verification/stack` хранит исходный compatibility-probe.

```sh
bun install --frozen-lockfile
cp .env.example .env
```

В `.env` задайте `DATABASE_URL`, случайный `BETTER_AUTH_SECRET` минимум из 32 символов и `APP_URL=http://127.0.0.1:5173`. Используйте отдельную базу, затем выполните:

```sh
bun run db:migrate
bun run admin bootstrap your-email@example.com
bun run dev
```

В другом терминале запустите `bun run dev:client` и откройте [локальное приложение](http://127.0.0.1:5173). Команда `bootstrap` печатает одноразовую ссылку: первый зарегистрированный по ней пользователь становится администратором и сам задаёт пароль. Открытая регистрация закрыта. В административном разделе доступны персональные приглашения, индивидуальное восстановление и регистрационные ссылки для нескольких новых учеников. Получатель общей ссылки сам указывает имя и email; после регистрации автоматически входит и открывает «Учебник» с пустым личным прогрессом. По умолчанию ссылка допускает 5 успешных регистраций за 7 дней; можно оставить только квоту или только срок, но хотя бы одно ограничение обязательно. Список показывает статус и позволяет отозвать ссылку. Условия не редактируются, полный URL копируется только при создании; отзыв не затрагивает уже созданные аккаунты. Из доверенной серверной консоли доступны также `bun run admin invite email` и `bun run admin recovery email`. Ссылки не отправляются автоматически; токен расположен во фрагменте URL. При создании и восстановлении аккаунта пароль должен содержать от 8 до 128 символов; существующие пароли не меняются.

API работает на `127.0.0.1:3000`, Vite проксирует `/api` с одного origin. `/health` проверяет процесс, `/ready` — доступность схемы базы и корпуса. Авторизованному пользователю доступен контракт `/api/openapi.json`.

## Проверки

```sh
bun run typecheck
bun test tests
bun run build
```

Интеграционные проверки требуют одноразовую локальную базу с именем `japanese_app_test`, применённые миграции и переменные `TEST_DATABASE_URL` и `JAPANESE_INTEGRATION_DATABASE_URL`, указывающие на неё. Без этих переменных соответствующие DB-проверки явно пропускаются. Обычная пользовательская база для тестов не используется. Проверка подготовительных файлов: `python3 scripts/verify_preparation.py`.

После сборки Album-проверка запускается командой `bun tests/helpers/run-guided-browser.ts verification/album-learning/flow.ts`; она использует отдельные API/frontend порты и UUID-учеников.

Самостоятельные browser-runner сохраняют новые отчёты и снимки в игнорируемую Git папку `test-results/` внутри проекта. Команды и границы прежних проверок — в [VERIFICATION.md](docs/VERIFICATION.md).

## Самостоятельное размещение

Производственный адрес: https://outboundserver.freemyip.com/ — HTTPS без номера порта; VPN и OpenGym продолжают использовать прежние адреса. Nginx на VPS завершает TLS, Caddy обслуживает собранный интерфейс, API и PostgreSQL доступны только внутри Compose.

Workflow [Delivery](.github/workflows/delivery.yml) проверяет каждый PR: frozen install, типы, уязвимости зависимостей, миграции и тесты на отдельной PostgreSQL, сборку и браузерный вход по приглашению. После принятия в `main` GitHub собирает Linux-образы и отправляет их в GHCR; отдельный SSH-ключ разрешает только выпуск конкретного коммита. Сервер закрепляет digest образов, создаёт внешнюю копию до миграции, проверяет readiness и восстановление после выпуска.

Копии шифруются restic и хранятся на втором сервере: часовые за неделю, ежедневные за месяц. Запуск каждые 30 минут оставляет запас для целевого RPO ≤ 1 час; восстановление проверяется ежедневно на отдельной базе. Цель RTO ≤ 4 часа принята, но полный перенос на новый VPS требует отдельного учения. Команды, первоначальная установка, откат и границы проверки — в [DEPLOYMENT.md](docs/DEPLOYMENT.md).

Свободный разбор сопоставляет подготовленные примеры и словарь. Для других фраз можно настроить OpenAI-совместимый сервис через `ANALYSIS_URL`, `ANALYSIS_MODEL`, при необходимости `ANALYSIS_API_KEY`; он включается только при явном `ANALYSIS_FREE_ONLY=true`. Эта настройка требует проверки условий выбранного сервиса оператором и не является доказательством бесплатной квоты. При ошибке или исчерпании квоты другой или платный сервис автоматически не вызывается. Качество внешнего провайдера по [контрольному набору](docs/AI-EVALUATION.md) пока не измерено.

## Материалы

- [Карта Starter A1](materials/marugoto-starter-a1/curriculum-outline.json): все 18 уроков / 9 тем / Can-do 1–50; структура всех уроков; рабочий корпус находится в `materials/course.json`.
- [Источники по урокам](materials/marugoto-starter-a1/source-manifest.json): 52 ссылки на грамматические заметки с раздельными статусами проверки.
- [Примеры трёх написаний](materials/examples/orthography.json): иллюстрация данных для каны, фуриганы и обычного написания.
- [Образец L4](materials/examples/lesson04.sample.md): авторские объяснения и задания для проверки контракта данных; готовность полного урока не заявлена.
- [Маскот](assets/mascot/manifest.json): 9 прозрачных PNG, [локальная галерея](assets/mascot/preview.html), [анимация](assets/mascot/ANIMATION.md) и [точные промпты](assets/mascot/PROMPTS.md).
- [Источники счётных суффиксов](materials/counters-sources.json): семь групп из Marugoto A1, числовые правила и допустимые варианты. Предметные слова допускаются по личной изученности; количества 1–10 доступны сразу, дальше — по уверенным первым ответам.
- [Иллюстрации счёта и промпт](public/counters/generation.json): исходный прозрачный PNG и WebP для интерфейса, созданные встроенным imagegen. [Аудиоманифест](public/audio/manifest.json) включает 734 подготовленных счётных выражения/суффикса. Полное прослушивание носителем не заявляется.

Озвучка подготавливается на macOS существующим голосом Kyoko; на сервер поставляются готовые файлы:

```sh
bun scripts/generate-counter-audio.ts
```

Команда использует существующий кеш по тексту произношения и проверяет наличие всех счётных записей. Контекстные чтения известных фраз задаются в `audioText`, отдельно от учебного написания; повторный импорт сохраняет эти поправки. Для новой редакции перед запуском API нужна миграция `0003_counter_progress` через обычный `bun run db:migrate`; старые расписания не сбрасываются.

После `bun run build` можно выполнить `bun tests/integration.counters.browser.ts` с `JAPANESE_INTEGRATION_DATABASE_URL`, указывающим на одноразовую `japanese_app_test`. Runner сам обслуживает сборку на временном локальном порту и удаляет своих тестовых учеников.

## Что уже принято

Собственный VPS в Амстердаме; до 100 аккаунтов / 10 одновременно занимающихся; email/пароль, ручные персональные приглашения, ограниченные регистрационные ссылки и индивидуальное восстановление; личные данные; общий прогресс между устройствами; весь Starter A1 с расширением; общее занятие с автоматическим чередованием конструкций, двух направлений словаря и аудирования; свободный разбор внутри упражнения с независимыми фильтрами; три вида написания с фуриганой по умолчанию; уютный кот-помощник. Смена вида сохраняет расписание. При недоступности бесплатного ИИ оплата автоматически не включается.

Техническая основа: Hono + Bun, PostgreSQL, без брокера. Конкретные frontend/auth/ORM/test-инструменты и pins перечислены в архитектуре и матрице совместимости; цели восстановления Q36 приняты 21 октября 2026 года.

## Проверка файлов

Из корня: `python3 scripts/verify_preparation.py`. Проверяются карта курса, манифест источников, формы и задания образца, PNG и внутренние ссылки. Пройденная проверка этих файлов не означает пройденную приёмку приложения или ИИ.

Библиотечные проверки запускаются отдельно по [инструкции probe](verification/stack/README.md). Исходный compatibility-probe локально проходил восемь проверок с PostgreSQL 18.4. Текущее приложение дополнительно проверено в GitHub CI на PostgreSQL 18.6/Linux и развёрнуто на VPS; прежние ограничения probe не описывают состояние production.

## Границы готовности

Рабочая версия и корпус всех 18 уроков реализованы. Исходная лексика извлечена из официальных русских указателей; авторские объяснения и упражнения сохраняют отдельные статусы независимой языковой проверки. Статическое японское аудио подготовлено отдельно от корпуса; шаблонные записи без конкретного произношения не выдаются как готовые задания на слух. Linux-контейнеры, PostgreSQL 18.6 и восстановление внешнего dump проверены. Нагрузка 10 учеников, полное восстановление нового VPS и качество внешнего ИИ требуют отдельных испытаний. Локальная Qwen3-8B на исходный VPS 1 vCPU / 2 GB / 20 GB без GPU не закладывается.
