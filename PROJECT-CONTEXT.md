# PROJECT-CONTEXT

- **Последняя локальная правка (02.11.2026):** единое деревянное верхнее меню во всех Canvas-разделах; учебник, справочник и практика используют обе страницы; список уроков без прокрутки с зарубками сохранённых этапов. Все 18 уроков помещаются при 1280×720; короткие экраны используют страницы. [Проверки и статус](verification/m8/wood-navigation-2026-11-02.md). На 5202 работает эта правка; замороженный кандидат M8 ниже остаётся историческим артефактом.

- **Проект:** японский по Marugoto — уроки, повторение, конструкции, счётные суффиксы, справочник и личные списки.
- **Стек:** TypeScript, React, Bun/Hono, PostgreSQL, ts-fsrs; новый интерфейс — PixiJS 8.22.
- **Этап:** локальная подготовка M8: основной Canvas и совместимый React интегрированы в root build/start, кандидат `94803e9d551cad3057b3f225c8c52fd05885d72b3e68effd75eee961de9c1e89`. [M8: проверки и ограничения](verification/m8/M8.md), адрес `http://localhost:5202/`, возврат `/legacy.html` того же origin. M7 аппаратно/на слух/пользователем не принят целиком; production-выпуск отдельно. Старые локальные сервисы сохранены.
- **Границы:** общий альбом, Б в первом подключённом сценарии, отдельный тренажёр каны, сохранность прогресса, работа только локально.
- **Готовность:** полный согласованный интерфейс, сохранение/восстановление результатов и проверки целевых устройств; выпуск отдельно.

Статистика отдельного тренажёра каны сохраняется в IndexedDB для ученика в том же профиле браузера/origin; между браузерами и устройствами не переносится, SQL-бэкап её не содержит. Основной `src/`, build и необходимые зависимости изменены локально в M8; production не изменён.
