# Материалы для подготовки корпуса

| Файл | Готовность | Назначение |
| --- | --- | --- |
| [curriculum-outline.json](marugoto-starter-a1/curriculum-outline.json) | Проверена структура 18 уроков / 9 тем / Can-do 1–50 | Идентификаторы, источники, привязки частей книг и начальная карта функций |
| [source-manifest.json](marugoto-starter-a1/source-manifest.json) | Проверен индекс из 52 грамматических ссылок; часть страниц прочитана | Поурочные первичные источники, словарные точки входа и область проверки |
| [orthography.json](examples/orthography.json) | Авторские примеры для отображения | Три вида написания и разметка фуриганы; не полный словарь курса |
| [lesson04.sample.json](examples/lesson04.sample.json) | Авторский образец, требует окончательной языковой проверки | 3 навыка, 12 форм/элементов, 6 заданий с данными написания и вариантами ответа |

В структурной карте `content_ready: false` означает, что учебное наполнение ещё не подготовлено. Нельзя импортировать эту карту и считать требование полного учебника выполненным. Обязательный состав и проверки описаны в [CONTENT.md](../docs/CONTENT.md).

Весь Starter A1 должен быть наполнен до объявления полной поставки: выбранные пользователем уроки управляют доступом к материалу, а не наличием материала в сборке. При расширении сохраняются прежние идентификаторы и расписания повторений.

Проверка подготовленных файлов: `python3 scripts/verify_preparation.py` из корня проекта. Она проверяет связность и целостность, а не достоверность всей грамматики или работу ещё не созданного приложения.
