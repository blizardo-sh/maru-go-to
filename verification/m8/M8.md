## Что интегрировано

Canvas находится в обычном `src/client/canvas`, использует общие root API/outbox/types вместо `@m4` и generated releases. Совместимый React перенесён из того же проверенного продолжения. Корневой Vite создаёт оба HTML и версионированные chunks. Bun/Hono обслуживает API и статику; отдельного M8 application server нет. `assets/canvas`, `public`, `materials/publications` включают используемые ресурсы и provenance. Lab, приватные JSON, профили, дампы, fixtures и диагностические логи не нужны сборке или runtime и не включены в кандидат.

CSP не расширена. В локальном Bun/static сервере HTML — `no-store`, ресурсы — `no-cache` с revalidation. Явные entry aliases работают для `/`, `/index.html`, `/album.html`, `/invite`, `/recover`, `/login`, `/admin`. Отсутствующие assets возвращают 404; путь к скрытым файлам/обход директорий запрещён. Docker/Compose/Caddy подготовлены с одним `CLIENT_ENTRY`; контейнерный запуск отдельно NOT_RUN из-за отсутствующих CLI.

Сохранены цельный кот v4, 18 семейств движений, пять окружений, принятая река и звук. Исправлены ошибки переноса и крайних размеров: динамический ключ atlas теперь совпадает с перенесённым glob; длинный русский перевод помещается полностью в короткий разворот, сохраняя общую ось вопроса/ответа. Фуригана и японский текст сохраняют прежние минимумы 12/18 px. Художественные ассеты не перерисовывались.

Схема/FSRS ради M8 не менялись. В root добавлены исторические 0004/0005 из проверенного серверного продолжения. `AUTH_COOKIE_PREFIX` необязателен; локальный M8 использует отдельный namespace, одинаковый для обоих renderer.

## Воспроизводимость и запуск

Команды выполняются в распакованном кандидате. Требуется Bun 1.4.3 и новый локальный клон PostgreSQL с проверенными материалами. Секреты задаются только окружением, их нет в этих документах.

```sh
bun install --frozen-lockfile
bun run typecheck
bun run build
bun scripts/release-candidate.ts
# Предварительно установить DATABASE_URL, BETTER_AUTH_SECRET, APP_URL.
# APP_URL должен совпадать с выбранным origin, для M8: http://localhost:5202.
AUTH_COOKIE_PREFIX=pixi-m8 HOST=127.0.0.1 PORT=5202 CLIENT_ENTRY=index.html bun run start
```

Независимая минимальная копия без lab/private releases установила frozen dependencies, прошла typecheck/build и совпала со всеми 8048 исходными/собранными файлами манифеста. Обычный start на отдельном M8 test-клоне проверен по семи URL. Диагностические пути недоступны. Изолированная проверка Docker COPY inputs проверяет полноту входов; это не заменяет сборку контейнера.

`ANALYSIS_PROVIDER` по умолчанию не задан; внешний AI выключен. Только локальный проверочный launcher на 5202 подставляет явно подписанный ответ «Локальный образец анализа». Он не входит в production runtime и не является внешним AI.

## Совместимый возврат интерфейса

Прямой переход на `/legacy.html` сохраняет origin, cookies, localStorage и IndexedDB. Для переключения корневых entry aliases остановить только свой локальный процесс и запустить тот же кандидат с теми же DB/auth/origin параметрами:

```sh
AUTH_COOKIE_PREFIX=pixi-m8 HOST=127.0.0.1 PORT=5202 CLIENT_ENTRY=legacy.html bun run start
# Возврат Canvas:
AUTH_COOKIE_PREFIX=pixi-m8 HOST=127.0.0.1 PORT=5202 CLIENT_ENTRY=index.html bun run start
```

Примеры выше используют текущий локальный namespace `pixi-m8`. При работе с другим окружением сохранять его существующий namespace. Не менять origin/порт, профиль браузера, owner, публикацию или cookie namespace. Не восстанавливать старую БД. Прогресс остаётся в текущей БД. Кана хранится отдельно в `japanese-kana-v1` и не входит в SQL backup.

`checks-m8-rollback.json` и `checks-m8-rollback-sql.json`: основной Canvas создаёт точный durable pending для guided и обычного review; storage refusal предотвращает POST/уход; после перезапуска persistent browser совместимый React доставляет те же payload/attemptId; HTTP 200 и ACK проверены; SQL содержит одну квитанцию и один зачёт на очередь. Для review первый POST уже был зафиксирован до потерянного ACK, повторная доставка не дублирует зачёт. Открыты две React-вкладки; наблюдаемая доставка одной очереди могла закончиться до открытия второй. После возврата Canvas нет повторного праздника; байты kana stats/sessions совпадают до/после.

## Ручной локальный сценарий и ограничения

Открыть `http://localhost:5202/`. Для M8 подготовлен отдельный новый профиль без автоматических оценок; доступ записан только в приватном `verification/m8/.local/M8-LOCAL-ACCESS.txt`. Начать первый урок, послушать слово, раскрыть ответ, выбрать самооценку; затем проверить учебник, счётчики, конструктор, кана и настройки. Возврат интерфейса доступен на `/legacy.html` того же origin. Старые сервисы 5196/5200/5201 не переключались. На финальной проверке портов они уже не слушали; причина завершения не установлена, автоматически они не перезапускались. Основной M8 5202 оставлен работающим, временный preview 5205 и отдельный Safari WebDriver 5206 остановлены.

Открыты физические iPhone/Safari и Android/Chrome, настоящий IME/autofill/VoiceOver/TalkBack, OS background, память/нагрев/производительность телефонов, человеческое прослушивание и итоговое принятие сценария пользователем. Docker/Caddy execution NOT_RUN. Production/remote DB/external publishing NOT_RUN и не разрешены. Перед выпуском нужны эти наблюдения, отдельное решение по конкретному кандидату и разрешение на фактическую поставку. Повторный desktop-прогон не закрывает аппаратные пункты.
