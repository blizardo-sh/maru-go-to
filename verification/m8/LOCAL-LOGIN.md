# Локальный автологин M8

Открыть http://localhost:5207/ — helper войдёт в подготовленный обычный аккаунт M8 и вернёт на http://localhost:5202/ . Уже действующий вход M8 сохраняется. Пароль не вводится и не включается в URL/страницу/журнал.

Запуск из корня репозитория (Bun 1.4.3):

```sh
bun verification/m8/local-login.mts
```

Основной стенд 5202 должен уже работать. Helper слушает только 127.0.0.1:5207, принимает Host localhost:5207 и same-origin POST. Использует manualUsers[0] из приватного M8 runtime и обычный sign-in API; проверяет owner и отсутствие роли администратора. Runtime guards запрещают прежние или удалённые БД. Cookies остаются штатными pixi-m8 на localhost, совместимыми с Canvas и React; статистика каны остаётся на origin 5202.

Это отдельное локальное удобство после заморозки M8. Оно не импортируется приложением, не входит в release allowlist и не меняет кандидат 94803e9d551cad3057b3f225c8c52fd05885d72b3e68effd75eee961de9c1e89. Для отключения остановить только процесс этого helper; при необходимости выйти из приложения штатной кнопкой.
