# Попытки проверок и исправления M8

Сырые логи/состояния содержат синтетические идентификаторы и хранятся только в .local; опубликованные результаты обезличены.

- Корневые unit fixtures ожидали старые маршруты A: legacy coverage явно сидирует старый persisted route, свежий опубликованный маршрут проверяет Б. После согласования fixture expectations — 204 PASS, 0 FAIL, 0 SKIP. Продакшен-логика ради старых expectations не менялась.
- Первая сборка ссылалась на перенесённый glob с прежним ключом atlas: подтверждённый дефект исправлен; добавлена проверка фактической доступности companion.
- Длинный перевод слушания, затем русский prompt в 640×320 выявили переполнение. Полная фраза вписывается в доступную строку, центры сохранены. Финальный тест 72 состояний PASS.
- Safari login получил 429: тест учитывает Retry-After. Запуск Safari при скрытом automation window давал timeout; native проверки требуют видимого окна, это не PASS реального OS background.
- Старый native helper использовал нестабильный keyboard focus: адаптирован проверенный M7 pointer helper, клавиатурные сценарии сохранены отдельно.
- Повторное использование синтетических counter/workspace/hidden-ACK профилей меняло оставшиеся задания; для независимых сценариев подготовлены новые профили, прежние результаты не удаляются.
- Асинхронное обновление модели раньше нарисованного кадра приводило к преждевременному поиску кнопок/счётчиков в kana и personal list harness. Ожидания привязаны к готовой модели и кадру; приложение ради теста не менялось.
- Видео-прогон прерывался при смене кандидата; частичные отчёты архивированы приватно и не считаются окончательным PASS. Итоговый каталог выполняется на замороженной основной сборке.
- Docker/Caddy отсутствуют: статическая проверка входов не объявляется контейнерным PASS.

Индекс содержит действующие результаты и их исходный candidate. Перенос доказательства между двумя M8 candidates допустим только при явной карте неизменных исходников/контрактов; старые M7 отчёты не подменяют M8 execution.

- Финальный Safari завершил 59 шагов урока и девять групп через настоящие focus/Enter с ожиданием двух кадров восстановления фокуса. Дополнительный координатный smoke через Computer Use не завершён: наблюдались document.hidden=true / document.hasFocus=false, затем noWindowsAvailable. Это отдельный NOT_RUN pointer smoke, не дефект приложения, доказанный этими наблюдениями.
- Каталог на финальном кандидате дал native video error 4 при длительных прогонах; HTTP HEAD конкретного публичного MP4 позже вернул 200 video/mp4. Повторы неуспешных позиций сохраняют прежние результаты; в последнем harness каждый worker имеет отдельный browser context и журнал HTTP медиа. Точная причина временных ошибок не приписывается сети без дополнительных данных.
