# Загрузка и смахивание ответа — 2026-11-03

Стенд: https://94.103.2.98:4443/.
Сборка: `ccfbdecf7418503430cf0c968c654ac68d93a2a70f248ad066bf53cfea990e51`.

## Согласованное поведение

Пользователь выбрал свайпы **только внутри страницы с ответом**, а не по всему развороту. После раскрытия влево — «Ещё раз», вправо — «Помню». Кнопки исключены из зоны жеста. Страница с вопросом оценку не выставляет. Касание для раскрытия сохранено.

Совет рассмотрел широкий захват и короткие жесты: Скептик отметил недостаток доступного расстояния у края; Практик рекомендовал короткие намеренные смахивания; Критик выделил риск случайной оценки при диагональном движении. Решение по ширине зоны определено ответом пользователя. Для коротких жестов сохранены минимальное движение, горизонтальное направление и защита от повторного отправления. ADR не добавлялся: решение локальное и обратимое. Термин «Смахивание ответа» внесён в глоссарий.

## Причины и исправления

Сохранение ответа планировало перерисовку, которая через `leaf.bind()` отменяла ещё работающий tween. Теперь состояние ответа обновляется как прежде, но перерисовка страницы ждёт окончания анимации. Сохранение по-прежнему начинает запись в durable outbox до декоративного движения. Ошибки сохранения не скрываются.

Движение указателя немедленно отрисовывало каждый pointermove: воспроизведение 12 событий давало 10 рендеров. Теперь события объединяются в один кадр requestAnimationFrame. Декоративный цикл не вызывает второй render одновременно с перелистыванием. Смена карточки не рисует старую страницу в исходном положении.

Фиксированный порог 64 px мешал начать движение у границы экрана. Теперь короткое уверенное смахивание распознаётся по скорости, а требуемое расстояние медленного жеста уменьшается с доступным пространством до края. Минимум — 18 px; вертикальные и неоднозначные жесты не оценивают ответ. Кнопки и страница с вопросом исключены.

Первый HTML раньше содержал только пустой stage; шрифт, renderer, картинки и данные загружались последовательно. Теперь простой оформленный статус виден до выполнения основного JS. Оформление и авторизованные данные загружаются параллельно; при долгом ожидании доступна повторная загрузка. Ошибка загрузки JS имеет явное сообщение.

Хешированные файлы сборки получили `public, max-age=31536000, immutable`. Остальная статика поддерживает ETag/304; HTML остаётся `no-store`. На тестовом порту 4443 включён HTTP/2. Авторизация, данные курса, алгоритм повторения и схема БД не изменены.

## Замеры и проверки

- Исходная проблема воспроизведена: картинка 353 438 байт не завершила загрузку за 12 с; клиент получил 163 168 байт. Origin отдавал её за 3 мс, RU-прокси — за 391 мс. Основная сетевая задержка наблюдалась на участке до клиента.
- Одинаковая картинка 180 596 байт: HTTP/1.1 через staging — 9,85 с; после HTTP/2 — 5,62 с. Это отдельные сетевые измерения, а не гарантия времени загрузки приложения.
- После выпуска: неизменяемая картинка имеет правильный cache-control, условные запросы картинок возвращают 304 за 154–156 мс. Внешний index.html совпал по SHA-256 с release manifest, `/health` — 200, `/api/me` без сессии — 401. Рабочий `/health` — 200.
- 22 теста, 151 утверждение — прошли. Тесты до исправления воспроизводили отсутствие кэша, отказ короткого свайпа и лишние рендеры. Проверены быстрые и медленные жесты у обоих краёв, вертикальные движения, мелкие случайные движения, исключение кнопок и вопроса, одно сохранение и удержание анимации до завершения.
- TypeScript и release-сборка прошли.
- В браузере вручную проверены мобильный короткий свайп вправо, свайп влево, раскрытие и следующая карточка; на компьютере свайп вопроса не оценивает, свайп ответа работает через границу страницы. Проверены видимый стартовый экран, вход прежней сессией и готовность опубликованного меню после перезагрузки.
- Учебные ответы отправлялись только локальным проверочным аккаунтом. На удалённом аккаунте ответы не имитировались. Контейнеры production и база стенда при выпуске не менялись.

## Ограничения

Физический iPhone и частота кадров на нём не измерялись. Устранены воспроизводимые причины обрыва и лишней отрисовки; обещания фиксированных 60 fps нет. Системный жест браузера у самого края экрана остаётся под управлением ОС. Первая загрузка на наблюдаемом медленном соединении по-прежнему заметна; загрузочный статус не означает, что сеть стала мгновенной.
