# Сверка пользовательских PDF со словарём и маршрутами L3/L4

Проверено 103 позиции: L3 — 46 на 4 страницах; L4 — 57 на 5 страницах. Все страницы PDF просмотрены после raster-render, строки сверены с layout text. Снимок фактического `loadCourse` включает авторские наложения всех уроков; для core проверены явные `part.words` маршрутов L3/L4. Каждая строка ниже относится к одной позиции PDF, даже если у неё несколько ID.

В рамках этого аудита продукт, Git, БД и документация репозитория не изменялись.

- L4 №16 **だれですか** — Нет самостоятельной Word/form записи фразы. В core l04-family-photo-01 уже есть このひとはだれですか。 («Кто этот человек?»), пример у word.a5e32b90deb17e6c.
- L4 №50 **ごにん** — Нет самостоятельной Word/form записи. Счётный механизм nin создаёт форму 5 людей; counter.nin.5 имеет статическое аудио. Не считаем это core Word-целью.

- L3 №4 **おなまえは？** — Нет самостоятельной Word/form записи вопроса. В core l03-business-card-01 есть おなまえはなんですか。 («Как вас зовут?»), пример у word.c4ae772a6dc8e374. Существительное おなまえ не приравнено к целому вопросу.
- L3 №33 **ことば** — Самостоятельного слова/формы ことば со значением language/word нет. Случайная подстрока в ошибочном чтении こうむいんことば не является совпадением и не засчитана.
- L3 №35 **すごいですね** — Полной фразы すごいですね в Word/form нет. Есть только связанное базовое すごい (word.9c77ef56bdbc1e1d), supplementary L3, «здорово»; это частичное покрытие, не полное совпадение.
- L3 №39 **なんですか** — Самостоятельной Word/form записи вопроса нет. Оборот なんですか уже есть в двух core-примерах おなまえはなんですか。 и おしごとはなんですか。; формы です сами по себе не засчитываются за вопрос.

По лексическим данным полностью отсутствует **ことば** в значении language/word. У **すごいですね** отсутствует целая фраза, но присутствует база すごい. **ごにん/ろくにん** уже генерируются счётным механизмом и имеют аудио, однако не являются самостоятельными Word/form записями урока. Три вопросительных выражения уже употреблены в основных примерах. Поэтому «7 отсутствующих слов/понятий» было бы неверным итогом.

## Варианты и неоднозначные совпадения

Пять квалификаторов формы включены в исходные core/additional счётчики: L4 №11 きれい（な） и №19 とうきょう → 東京 / явная kana-form; L3 №2 えっ → явная форма え, №18 необязательный おねがいします, №34 существительное じこしょうかい с необязательным （します）. Последний глагольный вариант отдельной записью не представлен. Шесть шаблонов с ～/〜 и пробелами помечены `template_notation`, а не скрыто нормализованы.

Смысловые ложные совпадения исключены: こ=ребёнок ≠ счётное こ; はは=мать ≠ смех; さん=уважительный суффикс ≠ 三. Два ID にん — дубли одного суффикса, а не два PDF-слова. Исходные английские глоссы сохранены в таблице; русские значения указаны фактически, без автоматического объявления полной эквивалентности всех оттенков.

## Границы и воспроизводимость

Core-связь определена строго по route→goals→parts→words.wordId после `loadCourse`, дополнительная — по `lessonIds` совпавшей записи. Формы проверялись по `forms.wordId`, их собственному написанию/чтению и смыслу. Похожая строка не заменяет отдельную фразу. Варианты/необязательные части PDF не размножают число позиций.

Это проверка полноты и связей данных, а не оценка качества всех переводов, произношения, UI-доступности или прохождения курса. Статус source-checked взят из данных, не является сертификатом носителя. «Есть аудио» для счётных форм подтверждено manifest/path, не новым прослушиванием.

Материалы checked: `materials/course.json`, `materials/learning/lesson-03.json`, `lesson-04.json`, фактический результат `loadCourse` с overlays всех уроков. SHA256 исходников и PDF, полный related-example evidence и точные counters находятся в `audit.json`; переносимая полная таблица — `audit.tsv`.

Источники PDF: `downloaded.pdf` (L4), `downloaded (1).pdf` (L3).

## Дополнительно найденное ошибочное чтение формы

У формы `marugoto.starter-a1.form.72709f1ee2b22e2c` для `こうむいん` записано `こうむいんことば` в kana/segment reading; основной Word имеет корректное `こうむいん`. Пользовательский PDF L3 стр.2 подтверждает короткое чтение. Это дефект формы, а не наличие отдельного слова `ことば`; исправление добавлено в согласуемый объём.
