# PixiJS: сцены с котом — изолированный прототип

Проверяем, как существующие фоны и кот приложения выглядят в PixiJS. Основные
`src/`, `public/`, зависимости приложения, API и база данных не меняются.
Ветка: `prototype/pixi-scenes`.

Из корня `japanese-learning`:

```sh
npm --prefix verification/pixi-scene run dev
```

Открыть http://127.0.0.1:5188/. Доступ только с этого компьютера. Сервер и БД
основного приложения для предпросмотра не нужны. Используются установленный
Node.js и Vite/TypeScript из основного проекта; PixiJS 8.22.0 установлен только
в этой папке. На новой машине сначала установить зависимости основного проекта,
затем выполнить `npm --prefix verification/pixi-scene ci`.

В предпросмотре:

- Пять исходных фонов: комната, сад, горы, река и Токио. Для портретной ориентации
  используются существующие мобильные изображения.
- Кот собран из имеющихся слоёв головы, тела и хвоста; дышит, моргает,
  следит за указателем, реагирует на поглаживание и пробные ответы.
- Фон и передняя листва слегка смещаются с разной скоростью; при смене локации
  фоны плавно переходят друг в друга. Есть небольшие атмосферные частицы.
- HTML-карточка с фуриганой показывает сочетание обычного учебного интерфейса
  и Canvas. Её можно скрыть, чтобы рассмотреть сцену целиком.
- Движение отключается кнопкой и при `prefers-reduced-motion`; в скрытой вкладке
  цикл отрисовки останавливается. Для поглаживания есть обычная кнопка с доступом
  с клавиатуры, помимо нажатия на кота.

Ответы демонстрационные: не обращаются к API, не записываются в хранилище браузера
и не влияют на учебный прогресс. Звук в этот прототип не перенесён.

## Проверки

```sh
npm --prefix verification/pixi-scene run typecheck
npm --prefix verification/pixi-scene run build
npm --prefix verification/pixi-scene run check
```

Последняя команда требует запущенный предпросмотр и установленный Google Chrome;
проверяет пять фонов, быстрые переключения, пробную карточку, нажатие на кота,
реакции, отключение движения, четыре размера экрана и reduced motion. Снимки
сохраняются в игнорируемую папку `test-results/`. Основные тесты приложения не
запускаются, поскольку его код не меняется.

`build` проверяет компиляцию. Существующие изображения и шрифты намеренно не
копируются в `dist/`: это локальный предпросмотр с исходными ассетами, а не пакет
для публикации. Для просмотра используйте `dev`.

## Границы эксперимента

Задние планы пока цельные иллюстрации: параллакс разделяет фон, переднюю листву
и персонажа, но не объекты внутри самого фона. Для глубины внутри комнаты/сада
понадобятся отдельные художественные слои. Новая графика не генерировалась;
источники и сведения об ассетах остаются в существующих `public/**/generation.json`.

Плавность на физических телефонах и Safari ещё не измерялась. До интеграции нужны
проверки реального урока, звука, загрузки и освобождения ресурсов в React.
