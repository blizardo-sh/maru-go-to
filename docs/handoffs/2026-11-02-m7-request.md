## 6. Инварианты и правила исправлений

- Reveal, локальная проверка и исправление не дают зачёт FSRS. «Помню» сохраняется отдельно от помощи/первой ошибки; обязательный повтор не превращается в ложное «Ещё раз».
- До POST и ухода листа точный payload/attemptId должен быть в durable outbox. Прогресс и сохранённый отклик зависят от валидного ACK. Storage failure предотвращает POST/уход. Retry не создаёт новую попытку.
- Кана — отдельная IndexedDB `japanese-kana-v1` для owner/азбуки/знака/направления с атомарной квитанцией/browser outbox. Это не словарный FSRS. SQL-бэкап не содержит эту статистику; другой origin/порт/профиль/устройство не обязаны её видеть. Не очищай пользовательский browser storage ради теста.
- Весь видимый UI остаётся Canvas; разрешённые исключения — native video и минимальный recovery, невидимые нативные службы ввода/доступности. Не верни гонку blur → draw → потерянный pointertap или hide/show полей на каждом draw.
- API/транспорт: b378244d9fc40a357dc8fafd931400e42b7e1752 → неизменённый M4 patch → M5 patch → M6 sound-продолжение. Alias `@m4` указывает на M5; M6 sound импортируется явно. Не считать старый root src действующим выпуском.
- Не редактировать generated `.local/*-release/src` и не отключать проверки хешей. Для необходимого изменения extracted/shared-кода оформи явное проверяемое продолжение с сохранением замороженного M6 и совместимой сборки для сравнения/отката. Не создавать новый сервер/patch только ради имени M7.
- Исправляй подтверждённые дефекты минимально; не перерабатывай принятый дизайн, FSRS или архитектуру без необходимости. Root src, зависимости/lockfile, production/deployment и удалённая БД вне этого этапа. Внешний AI по-прежнему выключен; ручной анализ использует обозначенную локальную заглушку.

## 8. Git и итог M7

Без `reset --hard`, `clean -f/-fd`, массовых restore/checkout, автоматического stash, переключения базы/ветки, rebase/amend чужого задела, force-push. Без `git add .`, `git add -A`, `commit -a`. Stage только свои проверенные пути/хунки. Не коммитить M4/M5/M6 молча. Небольшие собственные коммиты допустимы, если отделимы; иначе оставить локальные изменения с объяснением.
