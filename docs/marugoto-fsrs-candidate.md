Его отдельный лимит увеличен до 60 секунд, все проверки и общий лимит остальных тестов сохранены. Это бюджет сценария с упаковкой, хешированием медиа, переключениями и откатом, а не допустимая задержка API.

Документация production о почте, регистрации и завершённых проверках сохранена. Локальные пути и ссылки на непубликуемые отчёты заменены переносимыми описаниями.

API, SQL-миграции, контент и серверные скрипты не менялись при этой доработке. Прежняя Docker-репетиция относится к кандидату `f2d6822f…`; новые Linux-образы собираются и проверяются заново в PR CI. Эти образы не публикуются в GHCR.

## Воспроизведение CI

Использовать Bun 1.4.3, Chrome и отдельную PostgreSQL с БД `japanese_app_test` на localhost. Переменные `DATABASE_URL`, `TEST_DATABASE_URL` и `JAPANESE_INTEGRATION_DATABASE_URL` должны указывать только на эту временную БД.

```sh
bun install --frozen-lockfile
bun run typecheck
bun run db:migrate
bun test tests --timeout 20000
bun run build
python3 scripts/verify_preparation.py
bash deployment/check.sh
```

Полный перечень браузерных сценариев и Docker-проверок закреплён в [Delivery](../.github/workflows/delivery.yml). PR запускает `check`; `publish` разрешён только для `main` вне события `pull_request`. SSH-deploy требует отдельного `workflow_dispatch`.

## Выпуск и откат

До выпуска нужно установить актуальные `deployment/release.sh`, `deployment/backup.sh` и `scripts/content-package.py` в предусмотренные [процедурой выпуска](DEPLOYMENT.md) пути на хосте, предварительно сверив установленные версии. Само слияние PR не обновляет эти файлы хоста. Непосредственно перед переключением повторить проверку production, доступности хранилища, места и свежей резервной копии.

После начала запуска нового API автоматический возврат старого API запрещён: он не понимает новые команды и публикации. Рабочий откат сохраняет новый API и расширенную схему, переключая активный контент или `CLIENT_ENTRY`. Восстановление dump — отдельная аварийная операция с учётом записей, созданных после копии.

Преподавательская проверка языка и отдельное прослушивание TTS человеком остаются открытыми. Пользователь проверил предыдущий кандидат на телефоне; физическое устройство с точной окончательной сборкой повторно не проверялось.
