# Сценарии приёмки

Это условия проверки реализации, а не отчёт о пройденных испытаниях. Локальная реализация и фактическое покрытие описаны в [VERIFICATION.md](VERIFICATION.md); ограничения A21–A22 сохраняются. Исходный [compatibility-probe](STACK-COMPATIBILITY.md) не подменяет приёмку приложения. A06 и A18 дополнены требованиями равнозначных ответов и реального переноса мышью; A07, A08, A11 и A23 включают согласованное общее занятие; фактическое покрытие каждого сценария указано в VERIFICATION.

| ID | Сценарий | Ожидаемый результат |
| --- | --- | --- |
| A01 | Выполнен вход, затем выбрано «Тренировать» у урока на 320/390px и компьютере | Главная — «Учебник», действие доступно у каждого урока без ручных статусов, фокуса и Can-do-фильтров; запускается материал выбранного урока |
| A02 | Первая карточка раскрыта и завершена «Помню» либо «Повторить»; отдельно оставлены раскрытие без оценки, черновик и нейтральный пропуск | После подтверждения обе оценки подключают отдельный элемент к повторению; простое открытие, черновик и нейтральный переход не подключают материал и не означают освоение |
| A03 | Завершено первое знакомство со словом только в одном направлении | Оба текстовых направления и аудирование при готовой озвучке автоматически доступны для назначенного повторения; их статистика и расписания самостоятельны, оценка одного направления не записывает успех другим |
| A04 | Изученный навык конструкции назначен к повторению, но не каждое слово исходного примера проходило словарную карточку | Подготовленные исходные элементы доступны для задания; свободные замены используют изученное, а в тренировке также текущий урок. Ограничение материала отличается от грамматической ошибки |
| A05 | На одном навыке предъявлены два разных предложения | Обновляется один грамматический навык; конкретные предложения не получают отдельные расписания |
| A06 | В ответе о себе на возможность говорить по-японски собрана полная фраза «わたしはにほんごができます» или равнозначная «にほんごができます» | Допустимое опущение подразумеваемой темы засчитывается и при финальном сохранении; удаление が, другая способность, другое лицо или время не становятся успешным исходным ответом |
| A07 | Ученик исправляет промежуточный ответ конструкции и переходит к следующему заданию; отдельно исследует иную фразу | Правильное/неверное совпадение получает обратную связь без изменения прогресса занятия и расписания; при переходе один результат определяется финальным ответом на исходное целевое задание. Исследуемая иная фраза не получает оценку исходного задания; фуригана сама по себе не считается подсказкой |
| A08 | Начата тренировка урока; отдельно открыт раздел «Повторение» | Тренировка даёт до 10 новых слов и 2 конструкций, если они подготовлены; конструкции есть в каждой порции, «Продолжить» доступно без дневного лимита. Повторение выдаёт только уже изученные должные задания. Текущий план фиксирован, его прогресс не подменяет прогресс изучения урока |
| A09 | Написание переключено kana → furigana → kanji | Слово, направление, расписание и собранное предложение сохраняются; чтение корректно, окончания и катакана остаются на месте |
| A10 | В «Справочник → Личные списки» созданы список и слово без чтения, затем необходимые данные подтверждены | Черновик сохранён для доработки; «Тренировать» списка учит подготовленные слова независимо от уроков. Данные и прогресс видны только владельцу |
| A11 | После изменения фразы прошла пауза около 0,7 секунды; разбор A пришёл уже после изменения в B; отдельно собрана неполная фраза | Разбор запускается автоматически; ответ A не выдаётся за актуальный перевод B; неполнота показана без ошибки повторения; автоматический разбор не фиксирует учебную попытку |
| A12 | Исчерпана бесплатная квота ИИ | Понятная недоступность разбора; платный запрос не отправляется; подготовленные упражнения доступны |
| A13 | Тот же результат повторно отправлен после сетевого сбоя | До подтверждения прогресс и карточка не меняются; повтор использует тот же attempt. После подтверждения сохранён один результат, одно изменение расписания и один переход прогресса |
| A14 | Два устройства отвечают на одну предъявленную карточку | Первый принятый ответ меняет расписание, второй сохранён как дополнительная практика |
| A15 | Пользователь B запрашивает прогресс или личные слова A | Сервер отказывает; смена идентификатора в запросе не раскрывает данные |
| A16 | Прямая регистрация без приглашения; повторное использование или истечение ссылки | Публичный API также проверяет приглашение; вход или изменение учётных данных по недействительной ссылке недоступны |
| A17 | В предложении две одинаковые частицы | Оба экземпляра независимы при перемещении, смене представления и проверке ответа |
| A18 | Мышью переставлены соседние и несоседние элементы; отдельно перетаскивание недоступно | Фактическое движение мыши меняет порядок только выбранного экземпляра без оценки карточки; сборка по нажатию и с клавиатуры сохраняется, фокус виден |
| A19 | Подтверждена самооценка карточки; проверены правильный/неверный черновик конструкции, нейтральный разбор и выключенное движение | Короткая анимация сопровождается текстом и значком и не блокирует переход. Черновик не меняет прогресс или расписание; неполнота, исследование и сбой разбора нейтральны. При уменьшении/выключении движения остаются статичные текст и значок; упражнение не сдвигается |
| A20 | Проверяется сборка всего учебника | Подготовлены предусмотренные материалы всех 18 уроков; заголовки и структурные JSON не засчитываются как полный корпус |
| A21 | Выполняется контрольный набор ИИ | Пороги качества и p95 из AI-EVALUATION измерены и записаны, а не заменены заявлением о поддержке языков |
| A22 | На VPS выполняется целевая нагрузка и обновление релиза | Измерены ресурсы и ошибки; после обновления и проверенного восстановления прогресс сохранён |
| A23 | Ученик слушает слово или короткую фразу и нажимает на карточку; затем оценивает её, как текстовую карточку | До раскрытия японский текст и русский смысл скрыты, включая подписи доступности; после раскрытия видны оба. Вправо — «помню», влево — «повторить», сразу следующее задание; на компьютере доступны перетаскивание и стрелки, раскрытие доступно с клавиатуры; микрофон не запрашивается |
| A24 | После первого знакомства повторены текстовая и аудиокарточка слова; отдельно проверена недоступность звука | Доступные направления подключаются автоматически; без готового audioUrl остаются два текстовых формата. Оценка меняет лишь своё расписание; первое знакомство слова учитывается один раз. Недоступный звук обозначен явно и не создаёт ошибочное или успешное аудиоповторение |
| A25 | После порции нажато «Продолжить», после выхода вновь начата тренировка того же источника | Следующая порция доступна сразу, подтверждённое сохранено, предлагается неизученный остаток; повторная практика изученного урока остаётся доступной |
| A26 | Старый ученик имеет ручные статусы/фильтры и подтверждённую историю; другой — только вручную открытые уроки | Существующая история и общие элементы уроков сохраняются независимо от прежних фильтров. Ручное открытие без истории не выдаёт неизученные карточки в «Повторение» |
| A27 | В должных заданиях есть недавно изученное/трудное и старое просроченное | Частотный подбор отдаёт дополнительный вес недавно изученному/трудному, не вытесняя старые просроченные задания; будущие и неизученные задания не добавляются |
| A28 | Ученик B открывает учебник и повторение после работы ученика A | Общий корпус доступен обоим, но первое знакомство, личные списки, расписания и прогресс A не переходят к B |
| A29 | Открыт справочник, просмотрены слово/конструкция, частицы и обе таблицы каны | Личные изученные слова/навыки соответствуют текущему ученику; статические сведения доступны для просмотра. Просмотр и раскрытие не создают review-записей или изученности |
| A30 | В «Справочник → Личные списки» создан/изменён список и нажато «Тренировать» | Сохраняются прежняя личная функция, подтверждение данных и короткая тренировка; список другого ученика недоступен |
| A31 | Рабочая композиция просмотрена на широких CSS viewport и телефонах | Доска центрирована независимо от кота, предметы видны, текст/действия не перекрыты; локальный шрифт загружен с кириллицей, JP остаётся читаемым, горизонтального переполнения нет |
| A32 | Урок содержит черновики; первое знакомство со всем готовым материалом завершено | Прогресс достигает 100% по доступным к обучению словам и подготовленным навыкам; невводимые записи не делают урок навсегда незавершимым |

Автоматизировать проверки целостности данных, расписания, доступа и конфликтов. Отдельно выполнить лингвистическую оценку эталонов и ответы модели, а также визуальную проверку телефона/компьютера. Ни один тип проверки не подменяет остальные.

## Приёмка игрового оформления

Эти условия дополняют A01–A24 и не отменяют учебные проверки выше. Локальное выполнение и границы проверок описаны в VERIFICATION; полная производственная приёмка остаётся отдельной.

| Сценарий | Ожидаемый результат |
| --- | --- |
| Верхняя навигация переключает разделы | Главная — учебник; доступны повторение, справочник и настройки. Внутри выбранной тренировки виды заданий чередуются автоматически |
| Начато занятие, затем раскрыта/изменена/оценена карточка, изменены настройки и выполнен переход между разделами | Выбран один из пяти готовых рисованных миров; сцена, план, текущая карточка и черновик сохраняются до явного завершения. На возврате не создаются новая очередь и новый случайный выбор |
| Занятие скрыто другим разделом | Аудио приостановлено; клавиши не оценивают скрытую карточку и её фокус не перехватывает управление |
| Открыт новый план; отдельно выполнен выход и вход другого ученика | Случайный выбор выполняется для нового занятия; совпадение фона допустимо. Чужие черновик, план и прогресс не переносятся |
| Визуально сверены старт и конструктор на 1280/390px с прототипом и двумя референсами | Рама, бумага, навигация, элементы фразы, кот и стартовая композиция образуют цельный рисованный интерфейс; фактические состояния просмотрены до финальной сборки |
| Проверены компьютер и экраны 320/390px | Рабочая область занимает основную ширину, японский текст читаем, интерактивные элементы не меньше 44px; кот и оформление не перекрывают текст или действия |
| Кот реагирует на реальные события | Различимы раскрытие, воспроизведение, работа над фразой, актуальный разбор, подтверждённый результат и завершение; ожидание, исследование, неполнота и недоступность не создают штраф или запись повторения |
| Открыта аудиокарточка и включено уменьшение движения | Японский текст и смысл скрыты до раскрытия, включая доступные подписи; звук и раскрытие работают с клавиатуры/touch, микрофон не вызывается. Уменьшение движения сохраняет статичные позы и текст |
| Подробный разбор свёрнут вручную, затем изменено написание и подготовлена новая версия ответа | Контекст и один результат задания остаются видны; обычный rerender не раскрывает детали, новая версия раскрывает их. Полный текст доступен прокруткой; клавиши в analysis-регионе не оценивают карточку и не меняют SRS |


## Приёмка вступления и звуков сцены

Все шесть решений приняты; таблица задаёт ожидаемое поведение, а не заявляет проверку. Учебные условия A01–A32 остаются в силе.

| Сценарий | Ожидаемый результат |
| --- | --- |
| Явно начато новое занятие | Одна из пяти случайных локаций оживает около трёх секунд, затем камера приближает крупную карточку; пропуск доступен с клавиатуры. Очередь может загружаться параллельно, но вступление не создаёт SRS-записи и не принимает оценку скрытой карточки |
| Пропуск, reduced motion или animations=false | Пропуск сразу открывает карточку. При ограниченном движении нет zoom и ожидания трёх секунд; сохраняется конечное оформление |
| Проверены пять локаций и возврат в начатое занятие | У каждой сцены есть соответствующий региональный акцент; после вступления едва заметное движение остаётся по краям, карточка неподвижна. Навигация/настройки сохраняют сцену, очередь, токены, черновик и прогресс; вступление не повторяется |
| Браузер разрешает или блокирует звук | Явное начало пытается разблокировать аудио; отказ/недоступность оставляет работающее занятие. Тихая музыка без вокала и окружение сцены не выдают скрытый ответ |
| Фактически звучит японская речь, затем заканчивается или останавливается | Музыка и окружение приглушаются только по реальным событиям речи и восстанавливаются после остановки; верхнее отключение сцены не выключает японскую озвучку |
| Изменены выключатель и отдельные громкости; выполнены reload, выход и вход другого ученика | Музыка, окружение и эффекты имеют независимые уровни, сохранённые только для текущего ученика; японская речь независима. Другой ученик получает собственные значения |
| Раскрытие, завершённое перемещение, подтверждённые Good/Again и завершение | Есть короткий визуальный и звуковой отклик без сдвига карточки; Again поддерживающий. Повтор одного attempt не дублирует эффект результата |
| Черновик, исследование, неполнота, нейтральный переход и потерянный ACK | Нет ложного результата или оценочного звука. До ACK прогресс/расписание не меняются; повтор использует тот же attempt и один подтверждённый эффект |
| Переход в другой раздел, скрытие страницы, завершение и выход; затем возврат | Фон приостановлен вне активного занятия. Возврат возобновляет его без нового вступления и без изменения плана |
