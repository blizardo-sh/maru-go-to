# HTTPS приложения и существующий VPN используют порт 443

21 октября 2026 пользователь выбрал `https://outboundserver.freemyip.com/` и сохранение VPN и OpenGym. Nginx распределяет TLS-подключения по SNI: домен приложения направляется на локальный HTTPS, остальные подключения — на существующий Xray; PROXY protocol сохраняет адрес клиента для ограничений доступа. Образы собираются на GitHub, а отдельный SSH-ключ разрешает только выпуск коммита, прошедшего CI в `main`, без размещения CI-runner на VPS.
