# Личный импорт Anki остаётся на устройстве

5 ноября 2026 пользователь выбрал полный локальный разбор личного файла Anki и хранение его материала, медиа и прогресса только на устройстве, с переносом через отдельную резервную копию. Существующие серверные личные списки для этого сценария не подходят: приватность в учётной записи не заменяет требование не передавать личный набор на сервер. Это исключает автоматическую синхронизацию между устройствами и серверное восстановление; общий импорт остаётся отдельным действием редактора после предпросмотра и выбора урока и режима.
