# Выполнять модульный API на Hono и Bun

20 октября 2026 года пользователь выбрал Hono + Bun после сравнения с Next.js, NestJS, Fastify, Elysia и Node.js. Один backend обслуживает HTTP/JSON, серверные сессии, проверку упражнений и внешний ИИ; предметные операции оформляются явными модулями, интерфейс собирается отдельно в статические файлы. Выбор сокращает число framework-слоёв, сохраняя обязательные схемы, проверку владельца и транзакции; цена — собственные соглашения модулей и проверка зависимостей на закреплённом Bun, которую нельзя подменять обещанием полной совместимости с Node.
