# Включать новый материал в повторения после обучения

В Q1 и Q6 обсуждения тематических тренировок 24 октября 2026 пользователь заменил включение нового материала после первой оценки на последовательность «справка → обучение → успешная отработка → интервальное повторение», общую для новых и существующих тренировок. Ошибки остаются учебными попытками, но не делают ещё не отработанный материал изученным; завершения всей темы ждать не нужно, а уже накопленные личные расписания сохраняются. Для отдельных знаков хираганы и катаканы в Q2 подтверждено исключение: они проходят обучение и практику без добавления в интервальные повторения.
