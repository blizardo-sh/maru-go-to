# Смена написания сохраняет карточку и расписание

Кана, написание с фуриганой и написание без фуриганы — способы отображения того же слова; в Q27 согласовано единое расписание при их переключении. Альтернатива с отдельной карточкой на каждый вид изолировала бы различия сложности, но умножала бы состояния повторения при смене настройки. Идентичность словарной карточки включает слово и направление вспоминания; отображение в неё не входит. Отдельное обучение чтению кандзи при необходимости потребует самостоятельного продуктового решения.
