# Открывать числовые ступени отдельно для каждого суффикса

В Q11–Q15 принят рост от 1–10 до миллионов по диапазонам, независимо для каждого суффикса, с разнообразными примерами вместо обязательного перебора каждого числа. Переход требует в последних 20 числовых заданиях ступени минимум 18 уверенных первых ответов, 10 разных чисел и 3 задания на самостоятельное вспоминание; исправления первой ошибки служат тренировкой. Такая проверка позволяет расширять числовой диапазон без переноса уверенности с другого суффикса и без требования освоить все возможные сочетания; расписания отдельных карточек сохраняются. В Q17 для возраста отдельно установлен смысловой предел 1–120.
