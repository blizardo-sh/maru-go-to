# Хранить прогресс в PostgreSQL и начать без брокера

20 октября 2026 года пользователь утвердил PostgreSQL и отсутствие брокера на старте. Ответ и расписание фиксируются одной короткой транзакцией; live-разбор относится к актуальной версии фразы и не требует долговечной доставки после закрытия страницы. Это позволяет начать с одной БД и одного backend; если появится обязанность гарантированно завершать длительные задания после рестарта, сначала рассматривается очередь в уже имеющемся PostgreSQL, с идемпотентностью обработчиков.
