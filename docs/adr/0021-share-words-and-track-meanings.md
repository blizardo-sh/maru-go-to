# Одно слово, отдельное изучение его значений

6 ноября 2026 года пользователь подтвердил Q4: новое значение уже знакомого слова изучается и повторяется отдельно; словарная запись остаётся общей. То же значение в другой книге использует прежнюю историю и расписание. Один прогресс на все значения ошибочно признавал бы новый смысл изученным, а копия слова на каждый учебник создавала бы дубли.

Существующие ID, ответы и расписания A1 сохраняются. История старого общего задания не доказывает знание каждого отдельно выделенного смысла, поэтому её нельзя задним числом размножать на новые цели. Прежняя цель остаётся совместимой с ранее опубликованным содержанием; новый смысл получает самостоятельное изучение без сброса прежних результатов. Отметка «Уже проходил» для значения не распространяется на другие значения слова.

Решение принято для реализации по [плану](../marugoto-a2-implementation-plan.md). Это правило идентичности и прогресса, а не свидетельство уже выполненной миграции.
