# Повторять применения конструкций, меняя учебные примеры

Расписание повторений грамматики ведётся для конструкции в определённом значении, а не для отдельного предложения: цель — применять её с разными знакомыми словами, поэтому запоминание одного примера не должно определять освоение навыка. Альтернатива с отдельным расписанием каждого предложения проще связывает оценку с предъявленным заданием, но дробит общий навык и поощряет запоминание формулировки. Для слов предусмотрены отдельные словарные карточки со своим расписанием; их результаты не подменяют прогресс грамматического навыка. Решение согласовано в ответах Q10 и Q15.
