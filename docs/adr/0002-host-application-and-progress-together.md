# Разместить приложение и прогресс на собственном сервере

Основной вариант — собственный сервер с интерфейсом, сервером приложения и базой данных: нужны общий прогресс между устройствами, до 100 отдельных аккаунтов и серверные обращения к ИИ. Альтернатива с интерфейсом на GitHub Pages сохраняет необходимость отдельного сервера для пользовательских данных и внешних ключей, добавляя разделённое размещение; поэтому она не выбрана основным вариантом. Доступ по приглашениям и личные данные согласованы в Q17–Q19, email/пароль и ручные одноразовые ссылки — в Q28, исходный VPS указан в Q33. Это решение определяет совместное размещение; принятые позднее Hono/Bun и PostgreSQL уточнены в [ADR-0004](0004-hono-on-bun.md) и [ADR-0005](0005-postgresql-without-message-broker.md).
