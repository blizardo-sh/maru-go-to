# Открывать практику счёта вместе с пройденными словами

Практика счётных суффиксов становится доступна для каждого пройденного учеником слова учебника без ожидания завершения всего урока или предварительного изучения самого суффикса. В Q6–Q7 пользователь выбрал немедленную практику счёта знакомых предметов; альтернатива с ожиданием урока, вводящего суффикс, откладывала бы эту практику. Поэтому незнакомое счётное выражение допустимо, а незнакомое предметное слово — нет; личные списки доступный словарь этой практики не расширяют.
