# Повторять счётные ответы независимо от картинок

В Q9–Q10 согласованы самостоятельные расписания для выбора счётного суффикса и отдельных сочетаний «число + суффикс»; смена картинки сохраняет расписание той же задачи. Общее расписание для суффикса могло бы скрыть трудности отдельных чтений, а расписание для каждой картинки дробило бы один учебный ответ на несколько состояний. Ошибочные и неуверенные ответы возвращаются через несколько карточек в текущей тренировке до уверенного ответа; выход сохраняет уже полученные результаты. В Q21 это поведение распространено на обычные словарные и аудиокарточки; возврат создаёт новую попытку той же карточки, сохраняя её идентичность и гарантии подтверждённого сохранения.
