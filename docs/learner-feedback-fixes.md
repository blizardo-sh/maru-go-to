## Уже согласованное поведение

**Тесты с выбором.** Один выбор → авторитетный ACK → реакция → автопереход; ошибочное задание появляется позже. Используются существующие задержки Guided WordQuiz: 800 мс для правильного и 1600 мс для ошибочного ответа. Ошибка сети не переводит дальше; retry повторяет точный payload/attempt, сохранённый ACK не создаёт вторую оценку. Для счётных заданий учитываются все корректные `acceptedKeys` и правило помощи → «Повторить».

**Самостоятельное вспоминание в изучении и повторении.** Нажатие → ответ → оценка свайпом, клавиатурой или меню, без новых дублирующих кнопок оценки. Прежняя рекомендация «свайп только в Повторении» отменена. У вопроса отличимая текстура и заблокированный свайп; подсказка — «Нажмите, чтобы открыть ответ». Ответ сохраняет привычную бумагу и готов к свайпу; подсказка — «Влево — ещё раз, вправо — помню». Текстура означает доступность взаимодействия. Раскрытие не оценивает; стиль A, читаемость и размеры сохраняются.

**Озвучка.** Проверить подготовленные чтения частиц `は/へ/を` в контексте всех 18 уроков. Перегенерировать только фразы с подтверждённым изменением чтения через существующую локальную подготовку записей, с новым URL по содержимому. Отбор 218 фраз / 210 URL не означает 218 доказанных ошибок. Лексические `はは`, `はなします` сохраняются; в `ははは…` меняется только частица. Никакой слепой замены, нового провайдера или произвольного runtime TTS. Подготовленное чтение целой фразы валидируется; декодирование/длительность не выдаются за человеческое ревью произношения. Клиент воспроизводит готовый URL. Необязательный валидируемый `LearningExample.audioText` используется только офлайн-подготовкой записей; видимое написание не меняет.

## Варианты ответа: весь объём 18 уроков

В проверенных исходниках цель — отдельное `ふたり`, без `です`; `かぞくはふたりです` находится во вводном примере. Общий `learningChoices` выбирает первые подходящие anchors урока, без смыслового сопоставления. Для `ふたり` (`b46d8ae7ed1a2508`) все три формата дают `ちち / はは / あに / ふたり`.

Перечислены **305 размещений / 279 уникальных целей / 915 вопросов** трёх guided-форматов. В 42 размещениях (126 вопросах) все три отвлекающих ответа даже имеют противоположный `Word.kind` (слово/фраза). Это структурная нижняя граница, а не полная оценка качества остальных вариантов.

Нужно подготовить и проверить сопоставимые отвлекающие ответы для **каждого** guided-размещения, с ровно одним смысловым ответом. Охват включает людей, возраст, количества на `つ`, часы, деньги, родственников, действия, частотность, просьбы и целые фразы. Нехватка подготовленного материала должна обнаруживаться до выпуска; заполнять её случайными общими anchors нельзя. Числовая четвёрка `ひとり / ふたり / さんにん / よにん` — обязательный регрессионный пример, а не всё исправление. Обратное задание `こども` не должно получать числовые ответы из-за соседства в части.

Наборы не требуют заранее навязанной большой схемы или таксономии. Общий helper GET/POST сохраняет уникальность, чтения, синонимы, ID/SRS и идемпотентность. Устаревший неотправленный `INVALID_CHOICE` обновляет задание без оценки; принятый attempt возвращает прежний ACK до проверки новых вариантов.

## Критерии приёмки

- Проверить все 915 guided-вопросов: подготовленный полный набор, сопоставимость, ровно один смысловой ответ, уникальные ID/чтения и отсутствие синонимической неоднозначности. Неподготовленный набор не подменяется общими anchors. Регрессии охватывают перечисленные смысловые группы, `ふたり` и обратный `こども`; GET/POST согласованы, устаревший выбор не пишет оценку, старый ACK воспроизводится точно.
- Проверить перечисленные правки контекста/объяснений и оба `どれ`, согласованность примера `の` со сценой, токенами, переводом и аудио; сохранить IDs и историю. Отдельно защитить корректные собственные/чужие формы, лексические `は`, пример с `すし` и жизнь в одиночестве от массовой замены.
- Для Q1 пройти обычный выбор, задержанный/потерянный ACK, точный retry, реакцию 800/1600 мс и автопереход только после ACK; ошибка возвращается позже. Остаток колоды обозначает незавершённые карточки, а не будущие попытки; состояние при навигации/возобновлении не теряется. Сохранить acceptedKeys/помощь у counters и soundKey/отсутствие SRS у каны.
- Для Q2 проверить точные подсказки, текстуру вопроса со свайпом, заблокированным до раскрытия, привычную бумагу ответа, читаемость и неизменные границы на desktop/phone. Раскрытие не делает POST; свайп/клавиатура/меню оценивают ответ, короткий свайп возвращает карточку, ошибка сохранения даёт точный retry без второй оценки.
- Для реально изменённых записей проверить исходную фразу, подготовленное чтение, новый hash/URL, декодирование и длительность; неизменённые записи не генерировать. После общей заморозки пройти нужные unit/HTTP/browser-регрессии на изолированных UUID fixtures и dedicated test DB, затем обычные release gates и exact-head CI. Не сбрасывать учебный прогресс, outbox или расписание, не менять первичные сервисы; merge/deploy не входят в задачу.
