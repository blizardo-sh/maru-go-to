# Читаемость стойки и сложность закрепления — 29 октября 2026

Работа ведётся только в отдельном локальном стенде. Основной клиент, публикации
учебника, оценки, маршруты и расписание повторений этой правкой не меняются.

## Принятое решение по интерфейсу

**Q18 принят:** прокручивается учебный лист внутри неподвижной стойки. Продолжение
списка обозначается краем бумаги и действием «Ниже ещё уроки ↓»; после прокрутки
доступен возврат выше. Обычная полоса прокрутки не добавляется.

Причины ошибок предыдущего стенда:

- Высокий Canvas физически двигался вместе со страницей; JavaScript компенсировал
  движение фона уже после прокрутки браузером. Теперь Canvas размером с окно
  закреплён в viewport; смещается содержимое, а не окружение.
- Любой японский вариант длиннее шести символов переводил все четыре ответа в
  один столбец. Теперь число столбцов определяется измеренной высотой текста;
  длинная фраза сама по себе не требует четырёх отдельных рядов.
- Карточка знакомства добавляла 180px пустоты после примера. Пустота убрана,
  интервалы уменьшены, а размер рамки учитывает высоту окна.

На настольных размерах фразы со снимков помещаются вместе со всеми ответами.
Если окно слишком короткое, продолжение длинного листа явно обозначено бумажными
кнопками «Ниже ↓» / «↑ Выше» над постоянными действиями. На коротком телефоне
первичная подсказка доступна через «?», а краткая реплика кота получает постоянное
место: результат не должен вытеснять выбранный ответ.

Это обратимое решение представления; отдельный ADR для него не нужен.

## Факты о текущей сложности

Проверен выпуск `b378244d9fc40a357dc8fafd931400e42b7e1752`, соответствующий локальному
бэкапу; подготовка исходников описана в [стенде](../verification/pixi-ui-lab/CONNECTED.md).
Данные ответов учеников для этого анализа не открывались.

| Наблюдение | Что делает текущий код |
| --- | --- |
| Небольшие группы | В исходном уроке 2 группы 5 / 3 / 5 слов |
| Варианты ответа | Три заранее составленных неверных варианта из опубликованного каталога, не только из текущей группы |
| Будущие слова | Из 39 неверных вариантов — 16 из своего урока (включая 12 из своей группы), 18 только из будущих, 5 из предыдущего материала |
| Форматы | Японский → русский, аудирование и русский → японский используют выбор из четырёх |
| Дистанция | То же слово возвращается через N−1 других слов: в группе из трёх — через два задания |
| Ошибка | Возвращается в текущую часть; минимальная дистанция до повтора не задана |

Например, у «Повторите, пожалуйста» есть «медленнее», «послушайте» и «приходите
в гости» из урока 7. У わかりました среди вариантов встречаются слова из уроков
5 и 10. Возможность отсечь неизвестное или явно нерелевантное, короткая дистанция
и неизменный набор ответов — **гипотезы причин лёгкости**, а не измерение усвоения.

Источники кода выпуска: `src/shared/learningChoices.ts:24–40`,
`src/shared/learning.ts` (`mixedWordPractice`, `advanceLearningState`),
`src/server/learning.ts:98–101`. Сервер принимает именно опубликованный набор:
самовольная подмена вариантов только на клиенте приведёт к `INVALID_CHOICE`.

## Предложение для согласования

**Q19 ожидает ответа:** оставить короткое знакомство, а закрепление постепенно
смешивать с уже знакомым материалом, делать неверные варианты правдоподобными и
однозначными, давать попытку вспомнить до показа вариантов. Сначала сравнить
подходы в отдельном прототипе, сохранив действующие оценки и прогресс.

Лёгкий первый круг может служить знакомством с заданием. Я бы не увеличивал число
новых слов только ради трудности: это не устраняет выбор из готовых ответов и
повтор сразу после предъявления. Проверять стоит последующее удержание материала,
а не только число правильных ответов в первом круге.

В экспериментах с иностранной лексикой повторное извлечение ответа улучшало
отсроченное воспроизведение. Это поддерживает проверку памяти после первого
успеха, но не устанавливает оптимальный размер группы для нашего приложения.
[Karpicke & Roediger, 2008](https://doi.org/10.1126/science.1152408).

Выбор из вариантов тоже может помогать обучению, если неверные варианты достаточно
правдоподобны и требуют различения. Поэтому полное удаление выбора не следует
считать единственным решением.
[Little et al., 2012](https://journals.sagepub.com/doi/10.1177/0956797612443370).

После ответа Q19 остаётся согласовать:

1. Вспоминание без вариантов будет необязательной попыткой или обязательной
   проверкой. Само скрытие вариантов до нажатия не доказывает самостоятельный ответ.
2. Как смешивать новое и уже знакомое и что делать, если у начинающего ещё нет
   подходящего знакомого материала. Не добавлять незнакомые фразы ради ловушки.
3. Как сравнить результат: ошибки первой попытки, использование подсказок и
   воспроизведение после паузы. Нынешний успех выбора не выдавать за усвоение.

Изменение вариантов потребует новой проверенной публикации с сохранением ID;
новые обязательные шаги — отдельного решения о совместимости маршрутов. Пройденные
уроки не должны автоматически стать непройденными. FSM/pathfinding из `game-ai`
для этого не нужны; непроверенные варианты от генеративной модели не вводятся.

До этого согласования учебные правила стенда остаются прежними.
